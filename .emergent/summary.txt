<analysis>**original_problem_statement:**
The user initially requested a simple informational web application for an event called Backyard Ultra Santo Domingo 2026. The project started as a static React site built from content provided in PDF documents. Over time, the requirements evolved significantly, culminating in a request to build a full-stack, real-time race tracking system. This system needed a secure admin panel to manage the race (laps, athlete status) and a public-facing dashboard to display live statistics and participant progress. The list of participants was provided in a text file and used to populate the initial database.

PRODUCT REQUIREMENTS:
1.  **Informational Website:** A multi-page React application with pages for Event Info, Runner's Guide, Rules, Logistics, FAQ, and Sponsors.
2.  **Live Race Tracking System:**
    *   **Secure Admin Panel:**
        *   Login with a username and password.
        *   Control the current lap number.
        *   Mark athletes as DNF (Did Not Finish) or DNS (Did Not Start).
        *   A button to complete the current lap for all active runners simultaneously.
        *   A secure feature to reset the entire race database for testing, requiring a typed confirmation (REINICIO).
        *   Filters to view athletes by status (Active, DNF, DNS).
    *   **Public Dashboard:**
        *   Accessible via an En Vivo link in the main navigation.
        *   Display real-time statistics: Current Lap, Completed Laps, Active Athletes, DNF Athletes, DNS Athletes, and Total Kilometers for all athletes combined.
        *   A filterable, auto-refreshing table of all participants showing their BIB, Name, Status (Active, DNF, DNS), Completed Laps, and Kilometers.
        *   An Export to CSV button.
        *   A special Winner Section that appears only when one athlete is left and they complete one final lap.
3.  **PDF Viewer:** A flipbook style PDF viewer for the Runner's Guide, accessible via a modal.
4.  **Sponsors Management:** Ability to add new sponsors with their logo and description, maintaining alphabetical order.
